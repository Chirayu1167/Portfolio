## Structure

```
index.html        markup and all content
css/styles.css    design system, layout, atmosphere
js/main.js        interactions (no animation library)
fonts/            Barlow Condensed, IBM Plex Sans, IBM Plex Mono (self-hosted)
img/              atmosphere artwork (see below)
tools/art/        scripts that generate everything in img/
```

Static site, no build step: open `index.html` through any static server or GitHub Pages.

**Two worlds.** Each section declares `data-world="up"` (The Upside Down: red light, spores, lightning) or
`data-world="normal"` (Hawkins: neutral). Crossing between them plays one brief cut. Change a section's world by editing that attribute.

**Artwork.** Everything in `img/` is original, generated by the scripts in `tools/art/`
(`pip install numpy pillow scipy`, then `python gen_scenes.py`, `python gen_fix.py`, `python gen_back.py`).
It is not photography and uses no third-party or show imagery. To use your own photos instead, replace the file with the same name
(for example `img/scene-phoenix.webp`); nothing else needs to change. If an image fails to load, the page falls back gracefully.

**Motion model.** CSS handles the visuals; `main.js` toggles classes and drives small canvases. Content is hidden only while JS runs,
is always revealed, and the hidden state is removed afterwards. With `prefers-reduced-motion`, or with JS disabled, everything is visible immediately.
Slow ambient layers pause when off-screen, and the hero loop only runs while the hero is visible.

**Previews.** CyberFury and Phoenix use their real screenshots; the other three show a dim "No signal" tile (nothing is invented).
To add a screenshot, replace the `<canvas class="static">` inside that project's `.preview` link with an `<img>`.

**Certifications** stay in `index.html` but hidden, as in the original. Remove the `hidden` attribute to show them.
